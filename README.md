# Logistics Analyzer

Advanced data analysis and visualization of logistics/shipment operations, built with Python (pandas, numpy, matplotlib, seaborn).

The project simulates a realistic shipment dataset, runs exploratory data analysis (EDA), and produces a set of visualizations that surface operational insights — delay bottlenecks, cost drivers, and their impact on customer satisfaction.

## What it does

1. **Simulate** a 6-month, 1,200-record logistics dataset across 5 regions, 4 transport modes, 4 carriers, and 5 product categories — with realistic built-in relationships (distance drives cost & delivery time, weekend dispatch raises delay risk, etc.).
2. **Analyze** the dataset: central tendency/dispersion, categorical distributions, delay/SLA performance, cost breakdowns, and a full correlation matrix.
3. **Visualize** 8 charts covering distributions, relationships, and trends, saved as PNGs.

### Key finding
Sea freight is the network's primary delay bottleneck (~41% delayed vs. ~7% for Road), and **delivery delay — not cost — is the strongest driver of customer satisfaction** (r ≈ -0.44).

## Setup

```bash
git clone https://github.com/<your-username>/logistics-analyzer.git
cd logistics-analyzer
python -m venv .venv && source .venv/bin/activate   # optional but recommended
pip install -r requirements.txt
```

## Usage

Run the whole pipeline (simulate → analyze → visualize) in one command:

```bash
python run_pipeline.py
```

Or run each step individually:

```bash
python -m src.simulate_data   # -> data/logistics_dataset.csv
python -m src.eda             # -> outputs/eda_summary.txt (also prints to console)
python -m src.visualize       # -> outputs/charts/*.png
```

## Dataset schema

| Column | Type | Description |
|---|---|---|
| `shipment_id` | string | Unique shipment identifier |
| `dispatch_date` | date | Date the shipment left origin |
| `day_of_week` / `is_weekend` | string / bool | Derived from dispatch date |
| `region` | categorical | North, South, East, West, Central |
| `transport_mode` | categorical | Road, Rail, Air, Sea |
| `carrier` | categorical | Carrier A–D |
| `product_category` | categorical | Electronics, Perishables, Textiles, Machinery, Consumer Goods |
| `distance_km` | float | Shipment distance |
| `shipment_weight_kg` | float | Shipment weight |
| `transportation_cost_usd` | float | Total transportation cost |
| `promised_delivery_days` | float | SLA promise, by mode |
| `delivery_time_days` | float | Actual delivery time |
| `delay_days` | float | Actual minus promised |
| `is_delayed` | bool | Whether the shipment missed SLA |
| `fuel_surcharge_pct` | float | Simulated fuel surcharge |
| `damaged_in_transit` | bool | Rare damage flag, mode-dependent |
| `customer_satisfaction` | float (1–5) | Simulated satisfaction score |
